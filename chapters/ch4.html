PART III: Your Operating System

4. Technology and systems

KW Command is your core tool. Set it up properly once so it works for you every day, then let it enforce the habits you have not built yet.

In this chapter you will learn to

  • Complete the six-part Command setup in your first week.
  • Run a Command-centered daily rhythm.
  • Configure speed-to-lead so a new inquiry gets a reply in minutes, even when you are busy.
  • Decide when optional tools are worth adding.

The one-time setup

Do these six things in order during your first week (Appendix C is the checklist):

  1. Complete profile and Marketing Profile.
  2. Import contacts, deduplicate, and tag by relationship and source.
  3. Download/Create SmartPlans (8x8, Quarterly call plan, New lead plan, Post-close).
  4. Set lead routing rules (if on a team).
  5. Customize Opportunities pipeline stages.
  6. Install Command mobile app and turn on notifications.

Speed-to-lead

Figure 4. Speed-to-Lead Response Window

• Under 5 Minutes: Highest conversion window.
• 5 to 30 Minutes: Strong conversion.
• After 30 Minutes: Sharp drop-off. Most agents respond in hours; top producers respond in minutes.

The standard has two layers:

  1. Automated first touch (within 1 minute): SmartPlan sends immediate text and email.
  2. Live call (within 5 minutes): Turn on app notifications and call immediately. If unavailable, send a personal voice note or specific text.
● FIELD NOTE
Test your own speed-to-lead. Have a friend submit an inquiry on your Agent Site at 8 p.m. on a weekday. Time how long until they get a text, email, and call. Fix delays before spending money on ads.

Optional tools

Add tools like Follow Up Boss or AI texting assistants only when basic Command systems are running cleanly and lead volume justifies the cost.

KEY TAKEAWAYS

  • Set Command up completely in week one: profile, contacts, SmartPlans, routing, pipeline, mobile app.
  • Open and close every day in Command. Follow-ups before prospecting.
  • Speed-to-lead means an automated reply in a minute and a live call in minutes, not hours.
  • Add optional tools only when the basics are working and volume justifies cost.
