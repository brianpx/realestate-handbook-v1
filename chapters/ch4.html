PART III: Your Operating System

One tool, set up once, used every day. Command is where the system lives, and speed-to-lead is its first rule.

4. Technology and systems

KW Command is your core tool. Set it up properly once so it works for you every day, then let it enforce the habits you have not built yet.

In this chapter you will learn to

  • Complete the six-part Command setup in your first week.
  • Run a Command-centered daily rhythm.
  • Configure speed-to-lead so a new inquiry gets a reply in minutes, even when you are busy.
  • Decide when optional tools are worth adding.

The one-time setup

Command rewards agents who set it up completely and punishes those who set it up halfway. Do these six things in order during your first week. Appendix C turns them into a checklist.

  1. Complete your profile and Marketing Profile. Photo, bio, phone, email, license number, social links, brand colors. Everything Command generates for you pulls from here.
  2. Import contacts. Phone, email, social and any spreadsheet you have. Deduplicate, then tag each contact by relationship (sphere, past client, lead) and by source.
  3. Create or download SmartPlans. Start with an 8x8 for new sphere contacts, a quarterly call plan for the whole database, a new-lead plan with fast early touches, and a post-close plan. Table 5.1 lists the starter library and Appendix B has day-by-day versions.
  4. Set lead routing rules if you are on a team, so inquiries reach the right person instantly.
  5. Customize your Opportunities pipeline. Rename stages to match how you actually work (for example: New, Contacted, Appointment set, Active, Under contract, Closed) so your pipeline view is honest.
  6. Install the Command mobile app and turn on notifications for new leads and due tasks.

The daily rhythm

Once Command is set up, your day has a shape. Start in Command, work the follow-ups it hands you, prospect, hold appointments, and end in Command. The order matters: follow-ups come before prospecting because a lead you already have is worth more than one you have not met yet.

Speed-to-lead

When someone inquires online, they are usually sitting in front of a screen at that moment, and they have probably sent the same inquiry to two or three other agents. The agent who responds first with a real, human message is the one who gets the conversation. Response time is the single biggest factor you control in online-lead conversion.

Figure 4. Speed-to-Lead Response Window

• Under 5 Minutes: Highest conversion window.
• 5 to 30 Minutes: Strong conversion.
• After 30 Minutes: Sharp drop-off. Most agents respond in hours; top producers respond in minutes.

Figure 4. The speed-to-lead response window. Conversion is highest inside five minutes, still strong within about half an hour, and falls sharply after that. Most agents respond in hours. Top producers respond in minutes.

The standard is two layers:

  1. Automated first touch, within one minute. A new-lead SmartPlan sends a text and an email the moment the lead lands. It should sound like you and ask one easy question.
  2. Live call, within five minutes when possible, and always the same day. Turn on mobile notifications for new leads and step out of whatever you are doing. If you are with a client, let the automated text buy you time and call at the first break.

If you cannot make a live call within the hour, send a personal voice note or a short text that names the property or area they asked about. Specificity proves a human read the inquiry.

● FIELD NOTE
Test your own speed-to-lead. Have a friend submit an inquiry on your Agent Site at 8 p.m. on a weekday. Time how long until they get a text, an email and a call. Fix whatever is slower than you expected before you spend a dollar on ads.

Optional tools

Follow Up Boss, branded client apps, AI texting assistants and dialers can all add value later. Add them only when two things are true: your basic Command system is running cleanly, and you have enough lead volume that the tool pays for itself. A new agent with a working Command setup and 30 leads a month does not need a second CRM. A tool you have not mastered is one more place for a lead to get lost.

KEY TAKEAWAYS

  1. Set Command up completely in week one: profile, contacts, SmartPlans, routing, pipeline, mobile app.
  2. Open and close every day in Command. Follow-ups before prospecting.
  3. Speed-to-lead means an automated reply in a minute and a live call in minutes, not hours.
  4. Add optional tools only when the basics are working and the volume justifies the cost.
